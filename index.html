案件
Target
Windows PE binaries, x86-64. A reference implementation rather than a single payload.
Vector
  • Anti-debug via PEB.BeingDebugged, NtQueryInformationProcess, hardware breakpoint registers.
  • Anti-VM through CPUID hypervisor bits, registry artefacts and timing skew.
  • Runtime integrity: checksumming its own .text section to catch patches.
Why
Each check abuses an assumption the analyst makes — that the debugger is invisible, that a VM looks like bare metal, that the mapped image equals the file on disk. Break one and the payload branches to a decoy path.

Target
macOS endpoints. The companion gadget targets iOS; both assume the device may already be compromised.
Model
  • Post-compromise persistence: signing state, launch agents and daemons, TCC grants.
  • Integrity drift: SIP status, unsigned kernel extensions, modified system binaries.
  • Trust boundary failure: a device that passes one check once, then drifts.
Approach
Continuous evidence over point-in-time scoring. Signals are re-collected on an interval and aggregated into a verdict that gates access — not a single enrolment check.
Open
An agent cannot be trusted to police its own host — a compromised one can lie. The fix is remote attestation, which is the part still unsolved.

Test point

試験
TP-01 · find any input this accepts attempt 1 
// true for one shape of input
function check(s) {
  let h = 0x2f;
  for (const c of s) h ^= c.charCodeAt(0);
  return h === 0 && s.length === 4;
}

Solution

The accumulator starts at 0x2f and XORs every byte, so you need b1 ^ b2 ^ b3 ^ b4 === 0x2f. Pick any three bytes and the fourth is forced: for abc it is 0x2f ^ 0x61 ^ 0x62 ^ 0x63 = 0x4f — the character O, so abcO passes.
